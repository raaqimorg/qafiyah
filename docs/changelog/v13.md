# Version 13

Released 2026-10-15, deploying the merge of release pull request #341 into `main`. The changes below are what this release adds to the previous deploy (7f0f205, version 12 and two hotfixes).

## Hotfixes

Both went straight to `main` and were deployed before this release.

- 2026-10-13, 4b3279d: Alloy has a 512 MB memory limit, not 256 MB. Its own code and heap filled 256 MB (#337, closes #336).
- 2026-10-13, 7f0f205: a deploy applies the mounted configuration files that changed: the edge template with a graceful nginx reload, and the observability files by recreating their service (#339, closes #338).

## Changes

- Feelings: the `/feelings` wheel, from the database. A reader picks a feeling from the Feelings Wheel in Arabic, then a narrower one, and reads the classical verses that express it. DeepSeek classified every verse of eras 1 to 5, and the API serves the result at `GET /v1/feelings`. The pages are unlisted and carry `noindex` until the team reviews them (#288, closes #263).

## Release steps

Dump 0046 adds the feelings tables. `bun run db:reseed` ran first, then `bun run deploy`. The reseed rebuilt search, so no separate reindex was necessary.
