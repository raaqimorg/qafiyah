# Version 22

Released 2026-10-28, deploying the merge of release pull request #405 into `main`. The changes below are what this release adds to the previous deploy (9b6ecdd, version 21).

## Changes

- Data: dump 0047 hides one modern poet and his 94 poems, and adds the Nabati poet Hamad al-Mughallouth with one poem.
- Database: every poem's related list holds 10 poems. A poem outside the suggestion pool also gets poems by its own poet and of its own era, and the last slots fill from the pool (#406, closes #297).
- Docs: the 100-poem sample stays frozen, and is generated again only on schema changes (#404, closes #403).

## Release steps

Reseed dump 0047 (`bun run db:reseed 0047_28_10_2026`), then deploy.
