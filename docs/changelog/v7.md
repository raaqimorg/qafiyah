# Version 7

Released 2026-10-11, deploying the merge of release pull request #283 into `main`. The changes below are what this release adds to the previous deploy (4428bd5, version 6).

## Changes

- Tooling: an optional guard refuses commits, commit messages, and pushes that hold a name from a local list in `.git/info/forbidden-terms` (#282, closes #281).
- Docs: the deployment docs describe the sparse checkout on the production server: why, how to read it, what to do at each release, and how to undo it (#284, closes #280).
- Docs: `AGENTS.md` tells agents to report a local setup failure as an issue after they work around it, and to ask the user first (#285, closes #275).
- Web: the home page search area fills the screen, so the footer starts below the fold and search results no longer push it out of view (#287, closes #257).
- Web: the fallback fonts match Amiri's width, with the real `local()` names, and the collapsed poet bio is clamped by lines with a real button, so poet pages no longer jump when Amiri loads (#289, closes #286).
- Web: a reading toolbar under the poem metadata changes the font size and the spacing, switches the theme, and hides the tashkeel. Only the theme is saved, and the footer settings dialog is gone (#291, closes #290).
- Tooling: `bun run doctor` checks a contributor's tools and minimum versions, and `bun run dev` runs it first (#294, closes #292).
- Web: a toolbar button switches the site font between Amiri, Thmanyah, and Scheherazade New. The choice is saved in the browser and applies before the first paint. Truncated text no longer clips the tails, dots, and hamzas of Arabic letters (#295, closes #293).
- Web: the tashkeel button is highlighted only while the tashkeel is hidden (186f51d).
- Web: the mobile menu and close icons are plain, dimmed, and 24 px (3701982, 76aae59).
- Web: the filter clear button sits on its label line, not in the dropdown (6f4aef3).
- Web: buttons show the pointer cursor again, as Tailwind v4 no longer sets it (960228b).
- Web: the accusative forms in the Arabic noun definitions are correct (d2d5bad).
- Web: the Astro dev toolbar is hidden (4b02704).
