# Version 5

Released 2026-10-09, deploying the merge of release pull request #269 into `main`. The changes below are what this release adds to the previous deploy (cf09998, version 4).

## Changes

- Data: dump 0042 repairs the verse rows of 5,108 poems: notes and headings mixed into the verses, poems shifted by a half-line, two verses in one row, free-verse paragraphs, and poems stored more than once. It fixes 3,895 titles, so no title is over 38 characters, and it splits one record that held two poems into `UflU` and the new `NXRs` (#270, closes #264).
- Tooling: the commit identity test runs git without inherited `GIT_*` variables, so a push from a worktree no longer writes into the real `.git/config` (#267, closes #266).
- Docs: the deployment docs and the C4 model describe the Cloudflare custom, rate limit, and cache rules of 2026-10-09 (#268, closes #265).

## Release steps

1. Silence the Grafana alerts for 30 minutes, because the restore stops the API.
2. `bun run db:reseed -y`: restore dump 0042, start the new API, and rebuild the search index.
3. `bun run deploy`: the same build, and a purge of the Cloudflare cache, so cached pages show the new rows and titles.
4. Check the deploy with `bun run api:conformance prod`.
