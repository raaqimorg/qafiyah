# Version 8

Released 2026-10-12, deploying the merge of release pull request #302 into `main`. The changes below are what this release adds to the previous deploy (045777b, version 7).

## Changes

- Tooling: a missing actionlint fails the gate with its install command, as ShellCheck and hadolint do (#301, closes #300).
- Web: the verse column of amudi and nabati poems widens to fit its longest half-verse on wide screens, and on phones the halves drop their staggered indent, so a long half-verse keeps one line at the same font size (#308, closes #307).
- Data: dump 0045 cleans the corpus. Poems have three types (amudi 288,582, hurr 41,191, nabati 11,022), and the unused register, form, and majra fields and their tables are gone. It repairs the rows of about 10,000 poems and 230 titles, and drops 655 damaged rows from 553 poems. It merges 65 duplicates (their slugs answer 301), deletes 17 non-poem entries, and splits 61 joined entries into 251 poems, with a new anonymous poet for the Ottoman era (#306, closes #305).

## Release steps

1. Check the server disk with `df -h /`, and silence the Grafana alerts for 30 minutes, because the restore stops the API.
2. `bun run db:reseed -y`: restore dump 0045, start the new API, and rebuild the search index.
3. `bun run deploy`: the same build, and a purge of the Cloudflare cache, so the cached pages of merged poems answer 301 and the type filter shows the new counts.
4. Check the deploy with `bun run api:conformance prod`.
5. Add `0044_10_10_2026` to the sparse checkout on the server, so the old dump leaves the disk.
