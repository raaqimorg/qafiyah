# Version 16

Released 2026-10-21, deploying the merge of release pull request #362 into `main`. The changes below are what this release adds to the previous deploy (53dc8b9, version 15).

## Changes

- Data: the data snapshots (16 database dumps, 2 avatar archives, and 1 feelings file) move from git to the private R2 bucket `qafiyah-data`. A bucket lock refuses every delete and overwrite. `bun run dev` downloads the newest dump, `bun run data:push` uploads a new snapshot, and `bun run db:reseed <folder>` downloads only the named dump on the server (#360, closes #359).
- Data: git stops holding the snapshots. The 169 encrypted files, the passphrase scripts, `bun run dump:key:*`, and the 19 passphrase keys in both secrets files are gone. The old snapshots stay in the git history for now (#363, #359).
- CI: the `Changes` job checks out without file contents again, so its fetch skips the old snapshots in the history (#364, #359).

A plain deploy.
