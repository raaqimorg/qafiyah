# Version 10

Released 2026-10-13, deploying the merge of release pull request #314 into `main`. Version 9 (431dd7f) was released into `main` but never deployed on its own, so this deploy also ships it. The changes below are what this release adds to version 9.

## Changes

- Web: every crawler may read the site. `robots.txt` has one `User-agent: *` group that keeps only the private paths out, and nginx no longer answers archives, SEO bots, Yandex, and MegaIndex with `403`. It still refuses attack scanners, `libwww-perl`, `python-requests`, and an empty user agent (#313, closes #311).

A plain deploy.
