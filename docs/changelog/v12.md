# Version 12

Released 2026-10-13, deploying the merge of release pull request #335 into `main`. The changes below are what this release adds to the previous deploy (079c4be, version 11).

## Changes

All of them come from the first week of production metrics and logs, and from the stress tests of their fixes.

- Web: poet, meter, rhyme, theme, and collection pages build their path with the URL parser. A slug with Arabic letters no longer answers 500 (#328, closes #320).
- Observability: Alloy mounts the containerd socket, so cAdvisor reports each container again, and the container memory alert can fire (#328, closes #321).
- Deploy: `bun run db:reseed` restores the dump into `qafiyah_next` while the API serves, swaps the two databases in one transaction, and rolls the API. It refuses to start without the disk space for the second copy. Under load, a reseed went from 6,281 failed requests to 1 (#328, closes #322).
- API: a refused Postgres connection is tried again for up to 2 seconds before its 503, so a request waits through the reseed's swap (#328, closes #330).
- Infra: the edge gateway's connect timeout is 2 seconds, not 60. A request that picks a removed replica during a rollout now waits 2 seconds, not a minute (#328, closes #323).
- Web: the `/_astro/` scripts of every build from the last 7 days stay in the `qafiyah-web-assets` volume. A page from before a deploy still loads its scripts (#328, closes #324).
- Web: the Bun server keeps DNS answers for 5 seconds, not 30. Its API calls no longer fail or wait 20 seconds after an API rollout (#328, closes #327).
- Web: the container starts nginx after the Astro server listens. A new replica no longer answers 502 at its start (#328, closes #331).
- Observability: Grafana no longer logs each alert query at info level, about 52,000 lines a day (#328, closes #326).

## Release steps

A plain deploy. It recreates `web` (new volume), `alloy`, `grafana`, and `edge-gateway`, so Grafana asks for the sign-in again. The kept-scripts volume starts with this build, so the protection of #324 begins with the next deploy.

None. #325 and #329 were closed as not planned.
