# Version 4

Released 2026-10-09, deploying the merge of release pull request #260 into `main`. The changes below are what this release adds to the previous deploy (0b96694, version 3).

## Changes

- Data: dump 0041 gives 16,629 unknown-poet poems their poets, adds 461 poets with cleaned names, and merges 447 duplicate poet records into 380. Every absorbed poet slug and merged poem slug answers a 301, so no indexed page breaks (#255, closes #254).
- SEO: paginated lists put the page number in the title, descriptions name poets grammatically ("نظمها" and "من شعرائه" in place of "لـ"), descriptions leave out an unknown meter or rhyme, poets without a bio get sample poems in their description, a description no longer ends in ":.", and `robots.txt` keeps crawlers off `/poems/random` (#259, closes #252).

## Release steps

1. Silence the Grafana alerts for 30 minutes, because the restore stops the API.
2. `bun run db:reseed -y`: restore dump 0041, start the new API, and rebuild the search index.
3. `bun run deploy`: the website with the SEO fixes.
4. Check the deploy with `bun run api:conformance prod`.

Before the release, Grafana's disk alert fired at 88%. Removing the decrypted dump copies that earlier reseeds left on the server, and the Docker build cache, brought the disk to 73%.
