# Version 6

Released 2026-10-10, deploying the merge of release pull request #273 into `main`. The changes below are what this release adds to the previous deploy (ce707d5, version 5).

## Changes

- Data: dump 0043 merges 9,864 short poems into the longer poems that hold their text, and 11 duplicate poet records into one, so each text has one page and the old URLs answer 301. 1,574 of the merges cross poets: a named poet wins over an anonymous record, then the older era, then more poems. A long poem changes poet only when the other poet's copy holds 80% of it or more, and no collection poem changes poet. `UflU` and `NXRs` merge into `ekTP`, which holds both (#272, closes #277).
- Data: dump 0044 adds 2,210 Nabati and folk poems and 5 poets, and fills the bios, eras, genders, and avatars that known poets lacked. It adds the poem type `nabati`, so search can filter Nabati poetry, and the poem page lays out `nabati` verses like `amudi`. Avatar snapshot 0001 holds every live avatar (#279, closes #278).
- Secrets: the passphrase of avatar snapshot 0000 is in the dev and prod secrets (f55ab20).

## Release steps

1. Silence the Grafana alerts for 30 minutes, because the restore stops the API.
2. `bun run db:reseed -y`: restore dump 0044, which carries the changes of 0043, start the new API, and rebuild the search index.
3. `bun run deploy`: the same build, and a purge of the Cloudflare cache, so the cached pages of merged poems answer 301 and the search filters show the new type.
4. Check the deploy with `bun run api:conformance prod`.
5. Delete `poets/GqDu/avatar.webp` from R2: the avatar of a poet that dump 0043 merged into another.
