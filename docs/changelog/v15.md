## Changes

- MCP: a hosted, read-only MCP server at `https://mcp.qafiyah.com/mcp`, so AI assistants can search the catalog, quote verses exactly, and link to qafiyah.com. Its nine tools call the API with their own key. The API counts those calls for each address, and against an hourly and a per-second total. The `/developers` page and both `llms.txt` files list it (#356, closes #354).
- Dependencies: `lucide-react` 1.58.0 and `posthog-js` 1.438.12 (Dependabot #355).
