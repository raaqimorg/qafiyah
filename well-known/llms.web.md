# قافية (Qafiyah)

> Qafiyah is an open-source project dedicated to the Arabic language, making its poetic heritage freely accessible to researchers and poetry lovers alike. We're committed to a high-quality experience: precise search, an easy interface, and reliable texts we continuously review and improve. Site language is Arabic.

## Browse

- [Poets]({SITE}/poets): Paginated index of poets
- [Meters]({SITE}/meters): Classical Arabic meters (al-ʿarūḍ)
- [Rhymes]({SITE}/rhymes): Rhyme letters (qāfiyah)
- [Themes]({SITE}/themes): Thematic categories
- [Feelings]({SITE}/feelings): The Feelings Wheel in Arabic, with the classical verses that express each feeling

## Data & API

- [Public API docs]({API}/v1/docs): Read-only JSON HTTP API
- [Developers]({SITE}/developers): Free API keys and usage limits
- [API llms.txt]({API}/llms.txt): Machine-readable index of API endpoints
- [OpenAPI spec]({API}/v1/openapi.json): OpenAPI 3 specification
- [Random poem]({API}/v1/poems/random): Random poem slug (text/plain)
- [MCP server](https://mcp.qafiyah.com/mcp): For AI assistants (Claude, ChatGPT, Cursor, and other MCP clients): search the catalog and quote it, with a link to each poem
