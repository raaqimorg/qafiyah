# Scripts Agent Guide

Repo tooling and CI checks, Bun/TypeScript plus bash wrappers. Every routine entry point is exposed as a `bun run <name>` script in the root `package.json`; use those names rather than paths so flags and working-directory handling stay in one place. `bun run test:scripts` and `bun run types:scripts` cover this directory (tests sit next to their module as `*.test.ts`). `scripts/ci.ts` is the whole quality gate (`bun run ci`, `--no-docker` to skip the Docker phases, `--docker-only` to run nothing else, `--phase <name>` for one phase); GitHub Actions runs it on every push and PR (the non-Docker phases in one job, each Docker phase in its own, skipped when the change touches nothing that phase uses); `ci/phases.ts` is the phase selection those flags drive.

| `db/`         | dump lifecycle: resolve and decrypt, restore (on first boot, and in place by `db:reseed`), split, encrypt, the fallback sample, before/after state diffs, and `sql/` (the refresh functions and the sample query)                                                                                                                                                                                                                  | `db:reseed`; the rest are mounted by Compose or called from `dev/` scripts and the `local-db-edit` skill, and the dump ones are documented in `data/db/MAINTAINERS_GUIDE.md` |

| `well-known/` | renders `well-known/*` templates into the web app's generated module                                                                                                                                                                                                                                                                                                                                                               | `well-known:generate*`                                                                                                                                                       |
| `secrets/`    | SOPS/age wrappers and the secrets schema (`schema.ts` is the single list of allowed keys)                                                                                                                                                                                                                                                                                                                                          | `secrets:*`                                                                                                                                                                  |

| `accounts/`   | the accounts-database backup and the systemd timer that runs it on the VPS                                                                                                                                                                                                                                                                                                                                                         | none (systemd timer, see `docs/deployment/services.md`)                                                                                                                      |
| `corpus/`     | offline classical-form validation of the poem corpus (`export-corpus.sh`, `verify-classical.ts`, `apply-verdicts.ts`); reads the dev database and writes under `reports/`, which is gitignored                                                                                                                                                                                                                                     | `corpus:*`                                                                                                                                                                   |
| `lib/`        | shared helpers: repo root, file walking, tracked-file listing, the external-linter runner, snapshot writing, cargo dumps, remote/VPS helpers, the db container tag                                                                                                                                                                                                                                                                 | none                                                                                                                                                                         |
